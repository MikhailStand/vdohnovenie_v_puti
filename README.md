# «Вдохновение в пути»

Сайт студии йоги в Королёве с закрытой панелью управления. Посетители видят занятия, массаж, цены, абонементы и контакты. Владелица сайта может самостоятельно менять содержание, не редактируя код.

## Возможности панели управления

Панель открывается по адресу `/admin` на том же домене, например `https://vdohnoveniezdec.ru/admin`. Отдельный домен покупать не нужно.

- добавление, изменение, скрытие и удаление направлений и видов массажа;
- изменение цен и абонементов;
- загрузка фотографий;
- изменение контактов и основных текстов;
- смена пароля с подтверждением старого пароля;
- фиксированный шаблон карточек, который сохраняет дизайн сайта.

## Состав проекта

- Next.js и TypeScript — сайт, серверные маршруты и панель управления;
- PostgreSQL в Timeweb Cloud — тексты, цены, карточки, пользователи и сессии;
- S3 в Timeweb Cloud — фотографии;
- App Platform — сборка, запуск и автоматическое обновление из GitHub.

## Локальный запуск

Нужен Node.js 22.13 или новее и доступ к тестовой базе PostgreSQL и S3.

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

Заполните `.env.local` собственными данными. Этот файл содержит секреты и не должен попадать в GitHub.

## Переменные окружения

- `DATABASE_URL` — строка подключения к PostgreSQL;
- `DATABASE_SSL` — `true` для подключения с SSL;
- `ADMIN_USERNAME` — первый логин администратора;
- `ADMIN_INITIAL_PASSWORD` — первый пароль администратора, желательно от 16 символов;
- `S3_ENDPOINT`, `S3_REGION`, `S3_BUCKET` — параметры S3;
- `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY` — ключи S3;
- `S3_PUBLIC_BASE_URL` — публичный адрес бакета или подключённого к нему домена.

Первый администратор создаётся автоматически при первом открытии `/admin`. После входа пароль следует изменить в панели. Последующие изменения `ADMIN_INITIAL_PASSWORD` не заменяют уже установленный пароль.

## Размещение в Timeweb App Platform

1. Подключите репозиторий GitHub.
2. Выберите ветку для размещения.
3. Включите серверный режим приложения, не статическую публикацию.
4. Команда сборки: `pnpm run build`.
5. Команда запуска: `pnpm start`.
6. Добавьте все переменные из `.env.example` в настройках приложения.
7. Подключите домен к приложению и дождитесь выпуска SSL-сертификата.

Для проверки изменений создайте стенд из отдельной ветки и подключите к нему отдельную тестовую базу и отдельный S3-бакет. После проверки объедините ветку с основной — App Platform соберёт рабочую версию автоматически.

## Проверка перед отправкой

```bash
pnpm build
```

Никогда не публикуйте пароли, строку подключения к базе и секретный ключ S3 в репозитории, сообщениях или снимках экрана.
